# Домашнее задание к занятию "`Резервное копирование`" - `Скворцов Александр`

## Задание 1

1. Составьте команду rsync, которая позволяет создавать зеркальную копию домашней директории пользователя в директорию /tmp/backup
2. Необходимо исключить из синхронизации все директории, начинающиеся с точки (скрытые)
3. Необходимо сделать так, чтобы rsync подсчитывал хэш-суммы для всех файлов, даже если их время модификации и размер идентичны в источнике и приемнике.
4. На проверку направить скриншот с командой и результатом ее выполнения

**Команда выглядит следующим образом:**
```
rsync -avhc --delete --exclude '.*' ~/ /tmp/backup
```

**Подробное описание параметров:**

1. **a:** создание архива
2. **v:** для вывода подробной информации о процессе копирования
3. **h:** выводит размеры файлов в удобном для чтения формате (например, KB, MB, GB)
4. **c:** Принуждает rsync проверять файлы на основе их контрольных сумм (хешей), а не только по времени модификации и размеру.
5. **--delete:** удаляет файлы в целевой директории (/tmp/backup), которых нет в исходной директории (домашней). Это гарантирует, что целевая директория будет точной копией исходной.
6. **--exclude '.*':** опция указывает rsync игнорировать все файлы и директории, имена которых начинаются с точки
7. **~/:** сокращение для домашней директории текущего пользователя
8. **/tmp/backup:** целевая директория, куда будет создана копия

## Задание 2

1. Написать скрипт и настроить задачу на регулярное резервное копирование домашней директории пользователя с помощью rsync и cron.
2. Резервная копия должна быть полностью зеркальной
3. Резервная копия должна создаваться раз в день, в системном логе должна появляться запись об успешном или неуспешном выполнении операции
4. Резервная копия размещается локально, в директории /tmp/backup
5. На проверку направить файл crontab и скриншот с результатом работы утилиты.
